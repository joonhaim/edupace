Quick start

Run a pacing session in four steps

  1. Connect the device

    Plug in the EduPace console via USB. Open the Training page and allow the browser to access the serial device by pressing on the "CONNECT" button.

  2. Choose input mode

    Select Hardware if the Arduino console is available. It is recommended to use Google Chrome or Edge. Otherwise switch to the Virtual controller for keyboard / mouse practice.

  3. Select a scenario

    Pick a training case from the scenario dropdown (e.g. symptomatic bradycardia, undersensing, oversensing) and read the summary banner.

  4. Adjust pacing parameters

    Use the knobs (or virtual sliders) to set Rate, Output and Sensitivity. Watch the ECG, PACE/SENSE LEDs and HR tile to confirm capture and appropriate sensing.
